## Run locally

Requires Python 3 to serve the static files:

```bash
python3 -m http.server 8000 --directory dist
```

Open `http://localhost:8000`. There is no package installation or build step.

## Deploy on Vercel

Import this repository into Vercel and use the included configuration:

| Setting | Value |
| --- | --- |
| Framework preset | Other |
| Build command | None |
| Output directory | `dist` |
| Root directory | Repository root |

The portfolio contains only static HTML, CSS, JavaScript and local images. No environment variables or external API keys are needed.
